Docker 指令速查表 · 实施岗版

面向软件实施场景整理，只保留真正用得上的命令，按使用频率分类

容器生命周期 查看与排错 镜像管理 Dockerfile 指令 Compose 网络与数据卷

一、容器生命周期（最常用）

日常部署、启动、停止、删除都靠这几个
docker run -d --name mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 -v /data/mysql:/var/lib/mysql mysql:8.0
docker run 创建并启动容器 最高频
参数含义：-d 后台运行 · --name 命名 · -p 端口映射(宿主机:容器) · -e 环境变量 · -v 数据卷挂载
docker ps docker ps -a
docker ps 看正在运行的容器；-a 看所有容器(含已停止) 最高频
docker start 容器名 docker stop 容器名 docker restart 容器名
start 启动已停止的容器 · stop 停止 · restart 重启 最高频
docker rm 容器名 docker rm -f 容器名
rm 删除已停止的容器；-f 强制删除(运行中也删)。注意：删容器 ≠ 删数据，数据在卷里

二、查看与排错（实施岗 80% 时间在这）

容器出问题时，按这个顺序排查
docker logs -f 容器名
docker logs 看容器日志，-f 实时跟踪(相当于 tail -f) 排错第一步
docker exec -it 容器名 bash
docker exec 进入容器内部排查，-it 交互式终端(容器里是 sh 就用 sh)
docker inspect 容器名
docker inspect 看容器详细配置(IP、挂载、环境变量、网络等)
docker top 容器名 docker stats
top 看容器内进程 · stats 看资源占用(CPU/内存)

三、镜像管理

拉取、查看、删除镜像
docker pull mysql:8.0 docker images
pull 拉取镜像 · images 查看本地镜像列表
docker build -t myapp:1.0 .
build 根据 Dockerfile 构建镜像，-t 打标签(名字:版本)，. 表示 Dockerfile 所在目录
docker rmi 镜像名 docker tag 源镜像 目标名:版本
rmi 删除镜像 · tag 给镜像打标签(常用于加仓库地址)

四、Dockerfile 常用指令

实施岗只需「读懂 + 会改 + 会写最简单的」
指令作用示例
FROM指定基础镜像(起点)FROM tomcat:9.0
COPY把文件拷进镜像COPY myapp.war /usr/local/tomcat/webapps/
ADD拷贝(支持解压 tar、远程 URL)ADD app.tar.gz /opt/
RUN构建时执行命令(装东西)RUN apt-get install -y vim
ENV设置环境变量ENV JAVA_OPTS="-Xmx512m"
WORKDIR设置工作目录WORKDIR /app
EXPOSE声明端口(提示作用)EXPOSE 8080
CMD容器启动时执行的命令CMD ["catalina.sh","run"]
ENTRYPOINT容器入口(和 CMD 配合)ENTRYPOINT ["java","-jar"]
记忆口诀：FROM 是地基、COPY 搬东西、RUN 装软件、CMD 是开机命令。看懂这四个，就基本能读懂 90% 的 Dockerfile。

五、Docker Compose（一键编排多容器）

一条命令启动「数据库 + 应用 + Nginx」整套服务
docker compose up -d docker compose down
up -d 后台启动整套服务 · down 停止并移除整套 面试加分
docker compose ps docker compose logs -f 服务名
ps 看编排的服务状态 · logs 看某个服务的日志
docker compose restart 服务名
restart 重启某个服务，不用整堆一起重启

六、网络与数据卷

实施时最容易踩坑的两个点：网络不通、数据丢失
docker network ls docker network inspect 网络名
network ls 看网络列表 · inspect 看网络里有哪些容器、各自 IP
docker volume ls docker volume inspect 卷名
volume ls 看数据卷列表 · inspect 看卷挂载到宿主机哪里(找回数据靠它)
docker cp 容器名:/路径 宿主机路径
docker cp 在宿主机和容器之间拷贝文件(如拷日志、拷配置)
