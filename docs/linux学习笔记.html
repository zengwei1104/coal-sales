1. vi/vim 编辑器

vi / vim 是 Linux 最常用的文本编辑器，vim 是 vi 的增强版。

三种模式（核心概念）

模式进入方式作用
命令模式启动后默认移动光标、复制、删除、退出
插入模式按 i / a / o输入文字
底线命令模式按 :保存、退出、查找替换

完整操作流程

vi test.txt      # 1. 打开文件
# 2. 按 i 进入插入模式，输入内容
# 3. 按 Esc 退出插入模式
# 4. 输入 :wq 保存并退出

退出 / 保存

命令作用
:w保存（不退出）
:q退出（未修改时）
:q!不保存，强制退出（改乱时用）
:wq / :x保存并退出
ZZ保存并退出（命令模式直接按）

进入插入模式

按键作用
i光标前插入
a光标后插入
o下一行插入
O上一行插入

移动光标（命令模式）

按键作用
h j k l左 下 上 右
0 / $行首 / 行尾
gg / G文件开头 / 结尾
Ctrl+f / Ctrl+b下翻页 / 上翻页

删除 / 复制 / 粘贴

命令作用

yy复制当前行
p粘贴到光标后
u撤销
Ctrl+r重做

查找 / 替换

/关键词          # 向下查找（n 下一个，N 上一个）
:%s/旧/新/g       # 全文替换
:set nu          # 显示行号
:set nonu        # 取消行号
新手常见坑：乱按键没反应 → 先按 Esc 回命令模式；想退退不掉 → Esc 再 :q! 或 :wq。左下角显示 -- 插入 -- 说明在插入模式。
退出 SSH 会话：输入 exit 或按 Ctrl + D。

2. 为什么能运行 Java

因为电脑上装了 JDK（Java 开发工具包），并且配置了 PATH 环境变量。两个条件缺一不可：

  1. 装了 JDK：包含 java（运行）和 javac（编译）。
  2. 配了 PATH：把 JDK 的 bin 目录加入系统环境变量，终端在任意目录都能找到命令。
java -version    # 查看 Java 版本
where java       # 查看 java.exe 所在路径

3. 用户与用户组

查看当前用户

whoami    # 显示当前用户名
who       # 显示当前登录的所有用户

查看系统所有用户

cat /etc/passwd        # 每行：用户名:密码占位:UID:GID:描述:家目录:shell
cut -d: -f1 /etc/passwd # 只看用户名列表

用户组

cat /etc/group   # 所有组
groups           # 当前用户属于哪些组
groups 用户名    # 查看指定用户的组

查看用户详细信息

id            # 查看自己
id 用户名     # 查看指定用户，如 id root
注意：id 和 groups 后面要跟真实存在的用户名，且区分大小写（Linux 用户名通常全小写）。拼错会报 no such user。

4. root 超级用户

root 是超级管理员，UID/GID 都是 0。权限最高，但平时不建议长期用它登录。

切换到 root

sudo -i        # 切换到 root（推荐）
su -           # 切换到 root（需要 root 密码）
sudo 命令      # 以 root 权限执行单条命令

如何判断自己是 root

看命令行提示符结尾：

提示符含义
zengwei@主机:~$普通用户（结尾 $）
root@主机:~#root（结尾 #）

退出 root

exit    # 或按 Ctrl + D

练手：管理用户完整流程

useradd testuser      # 创建测试用户
id testuser           # 查看它的信息
userdel -r testuser   # 删除（-r 连家目录一起删）
root 操作风险高：删除文件不会进回收站、不二次确认，操作前务必想清楚。

5. 切换目录 cd

cd /etc          # 绝对路径
cd 目录名        # 相对路径（当前目录下的子目录）
cd ..            # 上一级
cd ../..         # 上两级
cd ~             # 回到 home 目录
cd -             # 回到上一次所在目录
cd /             # 根目录
Tab 补全：输入目录名前几个字母按 Tab 自动补全，按两下列出所有匹配项。

家目录（home）

普通用户的家目录在 /home/用户名，不在 /用户名。可以用 ~ 代表它：

echo $HOME         # 查看自己家目录路径（如 /home/zengwei）
ls -al ~           # 列出家目录内容（~ = /home/zengwei）
cd ~               # 回到 home；直接 cd（不带参数）效果相同
报错 ls: cannot access '/zengwei': No such file or directory 就是因为家目录在 /home/zengwei 而不是 /zengwei。用 ~ 最省事。

6. 新建目录 mkdir

mkdir（make directory）用于新建目录。

mkdir test             # 当前目录新建 test
mkdir /home/zengwei/a  # 指定绝对路径新建
mkdir a b c            # 一次新建多个
mkdir -p a/b/c         # 递归创建多级目录（父目录自动补上）
mkdir -m 755 dir       # 创建时指定权限

-p 最常用，没有它时父目录不存在会报错：

mkdir a/b/c      # ❌ a 或 a/b 不存在会报 No such file or directory
mkdir -p a/b/c   # ✅ 自动把 a、a/b 一起建好
目录名不能重名：已存在时再建会报 File exists。

删除目录：rmdir（只能删空目录）或 rm -r（递归删除，慎用）：

rmdir test    # 只能删空目录
rm -r test    # 删除目录及其所有内容

7. 删除文件/目录 rm

rm（remove）删除文件或目录，删了就没了，不进回收站，用前要想清楚。

rm file            # 删除单个文件
rm file1 file2     # 一次删除多个文件
rm -r dir          # 递归删除目录（-r 必须带才能删目录）
rm -f file         # 强制删除，不提示（-f force）
rm -rf dir         # 强制递归删除（最危险，慎用！）
rm -i file         # 删除前逐个询问确认（-i 交互式）

选项区别

选项含义说明
-rrecursive 递归删目录必须带，否则删不了目录
-fforce 强制不提示、不报错（文件不存在也不报错）
-iinteractive 交互每个文件删除前都问 yes/no

通配符用法

rm *.txt       # 删除当前目录所有 .txt 文件
rm *.log       # 删除所有 .log 文件
rm -r test*    # 删除所有 test 开头的目录/文件
危险命令（千万别执行）：
rm -rf / —— 删根目录，毁掉整个系统
rm -rf * —— 删当前目录下所有东西
rm -rf ~ —— 删光你的家目录
这些命令执行后无法恢复，root 用户下尤其要小心。

安全建议

  1. 删除前用 ls 确认目标。
  2. 用 rm -i *.txt 逐个询问，更稳妥。
  3. 别在 root 下乱删系统文件。

复制之前写过的命令，几种方法：

方法操作说明

9. 查看文件内容 cat

cat（concatenate）最常用功能是查看文件内容，把内容输出到屏幕。

cat file.txt          # 查看文件内容
cat a.txt b.txt       # 一次查看多个文件（按顺序拼接输出）
cat file1 > file2     # file1 内容写入 file2（覆盖）
cat file1 >> file2    # file1 内容追加到 file2 末尾
cat > new.txt         # 手动输入内容创建文件（Ctrl+D 结束）

常用选项

cat -n file.txt    # 显示行号
cat -b file.txt    # 显示行号（空行不编号）
cat -A file.txt    # 显示所有不可见字符（行尾 $ 等）

手动创建文件（重点）

cat > hello.txt    # 回车后进入输入模式
# 输入内容，每行一句
# 按 Ctrl + D 保存退出
cat hello.txt      # 再查看刚才写的内容

> 是重定向，把 cat 的输出（你敲的内容）写进文件。

cat 会把整个文件一次性全打印出来，大文件会刷屏。大文件更适合用 head（开头）、tail（结尾）、less（分页，按 q 退出）。
head file.txt     # 只看开头 10 行
tail file.txt     # 只看结尾 10 行
less file.txt     # 分页查看，上下翻页，按 q 退出

配合其他命令

cat file.txt | grep "关键词"   # 查看并过滤出含关键词的行

10. 分页查看 more / less

more 用于分页查看文件，一屏一屏显示，不像 cat 一次性刷完。

more 文件名

more 打开后操作

按键作用
空格向下翻一屏
回车向下翻一行
b向上翻一屏
q退出
=显示当前行号
/关键词搜索关键词（按 n 找下一个）

常用选项

more -5 file.txt    # 每屏只显示 5 行
more +10 file.txt   # 从第 10 行开始显示
more -c file.txt    # 翻页时先清屏再显示

more、less、cat 的区别

命令特点
cat一次性全打印，文件大时刷屏
more只能向下翻，功能简单
less能上下自由翻，功能更强（推荐）
实际使用中 less 比 more 更好用（能向上翻），按键两者基本通用。快速看文件用 cat，需要来回翻用 less。

11. 查看开头/结尾 head / tail

head 查看文件开头，默认前 10 行；tail 查看文件结尾，默认后 10 行。

head 常用用法

head file.txt        # 默认显示前 10 行
head -5 file.txt     # 显示前 5 行（-n 5 效果一样）
head -n 20 file.txt  # 显示前 20 行
head -c 100 file.txt # 显示前 100 个字节
head a.txt b.txt     # 查看多个文件（每个文件前加 ==> 标题）

tail 常用用法

tail file.txt        # 默认显示后 10 行
tail -20 file.txt    # 显示后 20 行（-n 20 效果一样）
tail -n 30 file.txt  # 显示后 30 行
tail -c 100 file.txt # 显示最后 100 个字节
tail -f app.log      # 实时跟踪文件末尾（看日志超好用，Ctrl+C 退出）

-f（follow）会让 tail 一直盯着文件，有新内容追加就立刻显示，非常适合看运行中的日志。

head 与 tail 对比

命令作用常见用法
head看文件开头head -20 file
tail看文件结尾tail -20 file
tail -f实时跟踪文件末尾tail -f app.log
看配置文件开头用 head /etc/passwd；实时盯日志用 tail -f app.log。

12. 复制文件/目录 cp

cp（copy）复制文件或目录。

cp a.txt b.txt              # 复制成 b.txt（复制并改名）
cp a.txt /tmp/              # 复制到 /tmp 下（保持原名）
cp a.txt /tmp/b.txt         # 复制到 /tmp 并改名
cp a.txt b.txt c.txt dir/   # 一次复制多个文件到 dir
cp -r dir1 dir2             # 复制目录必须加 -r（递归）
复制目录一定要加 -r，否则报错 cp: -r not specified; omitting directory。

常用选项

cp -r dir1 dir2   # 递归复制目录
cp -i a.txt b.txt # 覆盖前询问确认（-i interactive）
cp -f a.txt b.txt # 强制覆盖，不提示（-f force）
cp -p a.txt b.txt # 保留权限、时间戳等属性
cp -v a.txt b.txt # 显示复制过程（-v verbose）
cp -a dir1 dir2   # 归档复制，保留所有属性（备份常用）

注意点

  1. 目标重名会直接覆盖，想安全点加 -i。
  2. 复制目录别忘 -r（新手最常见错误）。

常见示例

cp /etc/passwd /etc/passwd.bak   # 备份文件
cp -r ~/project /tmp/backup/     # 复制整个目录
cp -a ~/project /tmp/backup/     # 归档复制保留属性（备份推荐）

13. 移动/重命名 mv

mv（move）移动文件/目录，也可以用来重命名。

移动

mv a.txt /tmp/              # 移动到 /tmp 下
mv a.txt /tmp/b.txt         # 移动并改名
mv dir1 /tmp/               # 移动目录（不用加 -r，和 cp 不同）
mv a.txt b.txt c.txt dir/   # 一次移动多个文件
mv 移动目录不需要加 -r，这点和 cp 不一样。

重命名（最常用）

mv a.txt b.txt     # 同目录下移动 = 重命名
mv oldname newname # 改名

常用选项

mv -i a.txt b.txt   # 覆盖前询问确认
mv -f a.txt b.txt   # 强制覆盖，不提示
mv -n a.txt b.txt   # 目标已存在则不覆盖
mv -v a.txt b.txt   # 显示移动过程

和 cp 的对比

命令作用目录是否需要 -r
cp复制（原文件保留）需要 -r
mv移动/重命名（原文件消失）不需要
目标重名会直接覆盖，想安全点加 -i。

常见示例

mv file.txt file.txt.bak    # 重命名（等于备份）
mv ~/a.txt /tmp/            # 移动到 /tmp
mv project project_old      # 目录重命名

14. 打包/压缩 tar

tar 用于打包和压缩，最常见就是解压各种 .tar.gz、.tar、.tgz 文件。

三个核心参数

参数含义
-ccreate，创建（打包）
-xextract，解压
-z用 gzip 压缩/解压（.gz）
-vverbose，显示处理过程（加不加不影响结果）
-ffile，指定文件名（一般都要带）
有 z → 处理 .tar.gz（压缩包）；没 z → 处理 .tar（纯打包不压缩）。c 打包 / x 解包，互相对应。

纯打包 vs 压缩打包

tar -cvf hello.tar hello          # 只打包不压缩（无 z）
tar -zcvf hello.tar.gz hello      # 打包 + gzip 压缩（有 z）

解压（最常用）

tar -xzf 文件.tar.gz              # 解压 .tar.gz
tar -zxvf 文件.tar.gz             # 解压并显示过程（-v）
tar -xvf 文件.tar                 # 解包 .tar（未压缩，不用 z）
tar -xzf 文件.tgz                 # .tgz 和 .tar.gz 一样
tar -xzf 文件.tar.gz -C /目标目录  # 解压到指定目录（注意是大写 C）

打包/压缩

tar -czf 打包名.tar.gz 要打包的目录   # 打包成 .tar.gz
tar -czf backup.tar.gz project/       # 打包 project 目录

只看内容不解压

tar -tzf 文件.tar.gz   # 列出压缩包内容（不真正解压）

参数组合记忆

写法拆解意思
tar -xzf / -zxvfextract + gzip + file解压 .gz 文件
tar -czf / -zcvfcreate + gzip + file创建 .gz 压缩包
tar -tzflist + gzip + file查看 .gz 内容
tar -zcvf 和 tar -czf 是同一个意思，参数顺序无所谓，-v 只是让你看得见过程。

常用压缩格式对照

文件后缀解压命令
.tar.gz / .tgztar -xzf 文件
.tartar -xf 文件
.tar.bz2tar -xjf 文件
.zipunzip 文件.zip
.gzgunzip 文件.gz

常见示例

tar -xzf nginx-1.20.tar.gz      # 解压源码包到当前目录
tar -xzf app.tar.gz -C /opt/    # 解压到指定目录
tar -czf code.tar.gz code/      # 打包 code 文件夹
tar -tzf code.tar.gz            # 查看压缩包内容

15. 网络与部署专题

网络接口 ip addr

ip addr 查看所有网卡和 IP 地址。

ip addr    # 查看所有网络接口
接口含义
lo回环接口，127.0.0.1，指向本机自己
ens160（或 ens/enp 开头）真实物理网卡，如 IP 192.168.73.128

关键字段：inet=IPv4 地址，inet6=IPv6，link/ether=MAC 地址。/24 表示子网掩码 255.255.255.0。

防火墙 firewalld

AlmaLinux / CentOS 用 firewalld，命令 firewall-cmd。普通用户操作防火墙必须加 sudo，否则报 Authorization failed。

sudo firewall-cmd --state                     # 查看运行状态
sudo firewall-cmd --list-all                   # 查看所有配置
sudo firewall-cmd --list-ports                 # 查看已开放端口
sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent   # 开放端口
sudo firewall-cmd --zone=public --remove-port=8080/tcp --permanent # 关闭端口
sudo firewall-cmd --reload                     # 重新加载（改了必须 reload）
加了 --permanent 是永久生效，但必须 --reload 后才真正生效；不加则是临时生效，重启失效。

常见端口对照

服务端口
SSH22
HTTP（网页）80
HTTPS443
MySQL3306
Redis6379
Tomcat / Spring Boot8080

端口的概念

一个 IP 对应一台机器，端口是机器上不同的"服务窗口"，每个服务占一个端口，互不冲突。

你的服务器 IP：192.168.73.128
后端（Spring Boot）→ 8080 端口
前端（Nginx）      → 80 端口
MySQL              → 3306 端口
SSH                → 22 端口

localhost 与 IP 的区别

localhost = 127.0.0.1 = 当前这台机器自己。它永远指你正在操作的那台机器。

在哪访问写法
在 Linux 服务器本机上localhost:8080 或 127.0.0.1:8080
在 Windows 电脑上访问 Linux192.168.73.128:8080（写 Linux 的 IP）
程序部署在 Linux 上后，从别的电脑访问要用 Linux 的 IP，不能再写 localhost。

浏览器访问的真实地址

网址拆成四部分：协议://IP或域名:端口/路径。真实地址永远是 IP:端口，域名只是 IP 的别名（靠 DNS 翻译）。

写法实际端口
http://域名默认 80
https://域名默认 443
http://IP:8080显式 8080

内网 IP 与公网 IP

类型范围/说明
内网（私网）IP192.168.x.x、10.x.x.x、172.16~31.x.x，只在局域网有效，互联网访问不到
公网 IP全球唯一，互联网上的服务器用

你能上 bilibili 是因为路由器做 NAT（地址转换），让你共用一个公网 IP 出去。但外面的人无法直接访问你的内网 IP。

让外网访问你的项目（三种办法）

  1. 路由器端口映射：公网某端口映射到你 Linux 的端口（需公网 IP）。
  2. 内网穿透：frp、ngrok、花生壳等，生成公网地址。
  3. 部署到云服务器：阿里云/腾讯云有公网 IP，正式上线做法。

前后端分离部署端口

前端（Vue 打包后 Nginx 托管）跑 80 端口，后端（Spring Boot）跑 8080，MySQL 跑 3306。

浏览器
  │ 1.访问 http://IP:80（前端页面）
  ▼
Nginx（80 端口）→ 返回 HTML/CSS/JS
  │ 2.页面 JS 请求后端
  ▼
Spring Boot（8080 端口）→ 查数据库
  ▼
MySQL（3306 端口）
访问三条件：同一局域网（网络通）+ 服务在监听端口 + 防火墙放行端口。三者都满足才能访问。

16. 进程管理 ps / kill / top

查看进程 ps

ps -ef 查看当前系统所有进程。

ps -ef           # 显示所有进程（全格式）
ps -aux          # 也显示所有进程，多了 CPU/内存百分比
ps -ef | grep java    # 配合 grep 找某个服务的进程

输出各列含义

列含义
UID运行该进程的用户
PID进程 ID（唯一标识，操作靠它）
PPID父进程 ID
CCPU 占用
STIME启动时间
TTY关联终端（? 表示后台服务）
TIME累计占用 CPU 时间
CMD启动进程的命令

结束进程 kill

kill 12345      # 正常结束进程（PID 12345）
kill -9 12345   # 强制结束（-9 强制杀死）

流程：先 ps -ef | grep 关键字 找到 PID，再用 kill PID 结束。

实时查看 top / htop

top      # 实时看进程和资源占用，按 q 退出
htop     # 增强版（可能需先安装）

top 常用快捷键：q 退出，k 杀进程（输入 PID），M 按内存排序，P 按 CPU 排序。

17. 搜索文件 find

find 按文件名、类型、大小、时间等条件搜索文件。

按文件名搜索

find / -name "文件名"        # 全盘搜索（从根目录开始）
find /etc -name "*.conf"    # 在 /etc 下搜所有 .conf
find ~ -name "test.txt"     # 在家目录搜
find . -name "*.java"       # 当前目录搜 .java

按类型搜索

find / -type f -name "*.log"   # f=普通文件
find / -type d -name "nginx"   # d=目录

按大小 / 时间搜索

find / -size +100M    # 大于 100M 的文件
find / -size +1G      # 大于 1G 的文件
find / -mtime -7      # 最近 7 天修改过的文件

忽略权限错误（推荐）

find / -name "nginx.conf" 2>/dev/null   # 忽略 Permission denied

配合执行操作

find . -name "*.tmp" -delete                # 找到后删除
find . -name "*.log" -exec ls -l {} \;       # 找到后执行命令

实用场景

find / -name "redis.conf" 2>/dev/null   # 全盘找文件
find /opt -name "*.jar"                  # 找 .jar 文件
find / -size +1G 2>/dev/null             # 找大文件（清理磁盘）
和 ls、locate 区别：find 实时搜索功能最强但慢，locate 走索引超快但可能不实时。

18. 文本搜索 grep

grep 在文件内容里查找关键词。

grep "error" log.txt          # 在文件里找 error
grep "root" /etc/passwd       # 找包含 root 的行
grep -n "error" log.txt       # 显示行号
grep -i "error" log.txt       # 忽略大小写

常用选项

选项作用
-n显示行号
-i忽略大小写
-v反向匹配（显示不包含关键词的行）
-r递归搜索目录下所有文件
-c只显示匹配行数（计数）
-l只显示包含关键词的文件名

递归搜索目录

grep -r "关键词" 目录/     # 搜索目录下所有文件
grep -rn "port" /etc/     # 在 /etc 下递归找 port，带行号

配合管道（最常用）

ps -ef | grep java              # 找 java 进程
ps -ef | grep nginx             # 找 nginx 进程
history | grep tar              # 历史命令里找 tar
cat log.txt | grep "error"      # 日志里过滤 error

正则表达式

grep "^root" /etc/passwd       # 以 root 开头的行（^ 开头）
grep "bash$" /etc/passwd       # 以 bash 结尾的行（$ 结尾）
grep -E "error|warn" log.txt   # 匹配多个关键词（或）
grep 和 find 的区别：grep 搜文件内容里的文字，find 搜文件名。

21. 报错排查

command not found

意思是「系统找不到这个命令」。常见三种原因：

  • 拼写/参数错误：如 rooy（应为 root）、head -f（-f 是 tail 的参数）。
  • 命令是两个词连一起了：如 ipaddr（应为 ip addr）。
  • 软件未安装：如 wget，需先 yum install wget -y。
排查方法：用 命令 --help 或 man 命令 查用法；不确定拼写时按 Tab 补全。
